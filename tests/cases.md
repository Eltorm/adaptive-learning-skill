Run at least three rows from distinct domain families after every meaningful
change. The full smoke set below uses six scales and domains.

For each case issue `/learn`, then one `/chapter` or `/explain`, and record:
scale fit, entry-point respect, dependency/mainline quality, domain lenses,
depth evidence, reliability handling, and assessment quality using the rubric.
