# Changelog

## 0.1.1 — 2026-09-11

- Added explicit mode routing, arbitrary-entry handling, and a learning
  contract.
- Added proportional topic-scale rules and L0–L6 adaptive mastery targets.
- Added internal graph edge types, minimal prerequisite diagnostics, domain
  adaptation, evidence states, and reconstruction/transfer checks.
- Added output contracts, quality gate, schemas, examples, and cross-domain
  contract tests.
- Kept the implementation stateless; persistence and autonomous memory remain
  roadmap items.

## 0.2.0 — 2026-09-11

- Added explicit cognitive-path selection, edge strengths, and A/B/C relationship
  exposure budget.
- Added opt-in portable learner state protocol (profile, graph, mastery,
  sessions, review queue) with provenance and conflict semantics.
- Tightened cross-domain examples: executable L4 task, historical evidence
  anchor, and prerequisite-bridged/scored biology checks.

## 0.2.1 — 2026-09-11

- Added concrete GAE cognitive-path example and writing-flow anti-pattern guide.
- Made L4 tasks self-contained with delayed rubrics and progress records.
- Added read-only state validation plus explicit state init/record/due commands.
- Added graph edge-target/cycle and session-integrity checks.

## 1.0.0-protocol — 2026-09-11

- Added portable graph merge with conflict preservation and evidence status.
- Added safe state archive export/import and read-only due/review operations.
- Kept hosted search, automatic reminders, and multi-user sync explicitly out
  of scope.

## 0.1.0 — baseline

- Initial MVP protocol: topic → scope → prerequisites → map → curriculum →
  lesson → practice → assessment.
