# Domain adaptation prompts

Select the lenses that make the learner able to do something in the target
domain. These prompts are deliberately non-exhaustive.

| Domain family | Useful lenses |
| --- | --- |
| Mathematics | definitions, assumptions, examples/non-examples, derivation, proof, counterexample |
| Physics/chemistry/biology | model, mechanism, variables/units, measurement, prediction, uncertainty |
| Computing/engineering | abstraction, state/data flow, algorithm, complexity, implementation, operations, failure |
| History/social science | sources, chronology, actors, causality, competing interpretations, uncertainty |
| Medicine/public policy/law | mechanism, context/population, evidence quality, current guidance, risks, uncertainty |
| Arts/languages/humanities | form, context, close reading, practice, critique, competing interpretations |

For mixed topics, state which lens governs each stage. Do not invent an
“interdisciplinary” list of facts without a reason for each connection.
