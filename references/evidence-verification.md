# Evidence and freshness procedure

Use this reference only when a claim may have changed, is disputed, research-
sensitive, safety-critical, or the user requests sources.

1. **Triage the claim.** Label it stable, time-sensitive, contested, uncertain,
   or version-specific. Separate facts from interpretation and recommendation.
2. **Choose evidence.** Prefer original papers/data, official standards or
   documentation, government/clinical guidance, and high-quality reviews. Match
   source type to claim type; a blog is not evidence for a clinical guideline.
3. **Check status.** For research, inspect date, corrections, retractions,
   replication/contrary work, and whether later consensus changed the reading.
   For software, record product/version and retrieval date.
4. **Calibrate language.** Use “established” only for well-supported claims;
   say “evidence is mixed”, “one interpretation”, or “I could not verify” when
   appropriate. Never silently fill a missing source.
5. **Present economically.** Put a short source note beside claims whose
   provenance matters and offer a source list when requested. Do not flood a
   stable conceptual explanation with decorative citations.

If browsing is unavailable, narrow the claim, state the limitation, and give a
verification path instead of inventing recency.
